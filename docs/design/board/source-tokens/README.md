# Original ART-002 token sources

These three sheets are byte-for-byte snapshots of the original runtime direction sheets before ART-014 applied NOCTURNE. The DRYDOCK and PULP HORIZON runtime sheets and their metas were removed only after the asset reference audit; the chosen runtime sheet retains its GUID. The original font URLs below describe unproduced look-test inputs and are historical reference text, not Unity assets or licence claims.

`export_board_tokens.py --check` and the existing checker fixtures use these snapshots so the reference board and its three CSS files remain unchanged. Their generated-file headers retain the original source paths as provenance. Do not replace these snapshots when changing production `tokens.uss` or regenerating fonts. The look book, silhouettes, renders and Blender sources are unchanged.
